This technical report documents the completion of Week 2 of the virtual internship program at YuvaIntern, focusing on mastering the principles of Object-Oriented Programming (OOP) in Java. The primary objective of this milestone was to transition from procedural coding to building scalable, modular, and enterprise-grade software architectures. The deliverable provides in-depth conceptual explanations, verified code implementations, and console execution outputs across the core pillars of Java OOP: classes, objects, encapsulation, inheritance, polymorphism, and abstraction. Data hiding and state protection were established through encapsulation using private attributes and validated mutators. Hierarchical code reusability was achieved via inheritance, while compile-time method overloading and dynamic runtime overriding demonstrated polymorphic flexibility. Furthermore, architectural contracts and implementation decoupling were formulated using abstract classes and interfaces. A dedicated analytical section examines the critical importance of OOP in industry, illustrating how loose coupling, maintainability, and clean design patterns empower high-concurrency enterprise applications and modern AI/ML data ingestion pipelines. Developed through rigorous compilation, testing, and debugging, this report validates the intern's capability to design robust, clean, and reusable software systems adhering strictly to professional software engineering standards.
