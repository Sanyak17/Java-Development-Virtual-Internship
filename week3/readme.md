This technical report outlines the progress, implementations, and analytical findings completed during Week 3 of the virtual internship program at YuvaIntern, centered on mastering fundamental and advanced Data Structures in Java. The primary objective of this milestone was to evaluate in-memory data organization and algorithmic efficiency to optimize application performance and memory management. The deliverable provides in-depth theoretical explanations, verified code implementations, and terminal execution outputs for core linear and non-linear data structures: dynamic Arrays, Singly Linked Lists, Stacks (LIFO), Queues (FIFO), Binary Search Trees (BST), and HashMaps. Each data structure is evaluated under rigorous Big-O asymptotic notations, comparing time complexities for search, insertion, and deletion operations alongside space overhead. Practical enterprise use cases are analyzed, illustrating how Stacks manage recursive call traces, Queues coordinate asynchronous job scheduling, Binary Trees enable hierarchical range queries, and HashMaps deliver high-velocity O(1) O(1) key-value lookups. Developed through iterative coding, unit testing, and complexity profiling via the Java Development Kit (JDK), this report demonstrates the intern's ability to select optimal data structures for high-throughput enterprise backends and AI/ML data preprocessing pipelines, adhering strictly to industry standards. This foundation prepares the system for thread-safe concurrent buffers, stream file persistence, and indexed relational database transactions in subsequent weeks.
